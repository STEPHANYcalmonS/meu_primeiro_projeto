# Meu Primeiro Projeto Tech

Projeto utilizado na oficina **Git e GitHub** do ElasTitam | Casa Aberta.

## Objetivo

Este projeto foi criado para praticar:

- inicialização de um repositório Git;
- criação de commits;
- conexão com um repositório remoto;
- envio do projeto para o GitHub.

## Arquivos

- `index.html` — estrutura da página;
- `style.css` — estilos visuais;
- `imagens/` — pasta reservada para imagens.
